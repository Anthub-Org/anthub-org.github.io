Approvals

Review an application

Section titled “Review an application”
  1. Open Approvals and search the pending shop list.
  2. Select Open Store to review the owner’s and business’s details, application-review information, and ownership attestation.
  3. Confirm the information meets your team’s requirements. If it is incomplete, follow the approved review process before deciding.
  4. Select Approve to approve the application, or Suspend if the shop must be blocked.
  5. Check the updated status in the list or Store Details before moving to another application.
